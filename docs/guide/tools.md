# 内置工具与审批

Agent 的动手能力来自 18 个内置结构化工具，其中写文件、改文件、执行命令属于高危操作，默认需要用户审批。本页介绍全部工具、审批流程与工具结果的展示方式。

## 内置工具一览

| 工具 | 功能 |
| --- | --- |
| `list_files` | 浏览目录结构，排除隐藏文件 |
| `read_file` | 读取文件（行范围，带行号，start/end 自动交换）；传目录直接列出条目；二进制文件检测拒绝 |
| `glob` | 按文件通配符模式查找文件（如 `src/**/*.py`） |
| `search` | 搜索代码内容（优先内置 ripgrep 15.2.0——随项目分发于 `bin/rg.exe`，零安装；其次系统 PATH；都没有时降级为内置正则搜索，结果首行标注「已降级」，正则语义不变） |
| `web_search` | 搜索网络（Parallel / Exa 免费匿名 / Tavily AI 优化，可切换；type / livecrawl / context_max_chars 透传 Exa） |
| `webfetch` | 抓取网页正文（HTML 转纯文本，保留链接地址；响应 5MB 上限，超长正文走统一截断落盘） |
| `skill` | 加载用户技能包（SKILL.md 指令 + 附带文件清单；name 留空列出可用技能） |
| `task` | 派生子代理独立完成子任务（独立上下文、受限工具集，返回最终汇报；默认异步，background=false 同步等待；高危需审批） |
| `write_file` | 创建/覆盖文件（自动创建父目录；保持原文件行尾与 BOM；写 .py 附语法检查） |
| `patch_file` | 替换文件中的文本（精确优先，逐级宽松匹配；replace_all 全量替换；保持行尾/BOM；改 .py 附语法检查） |
| `run_shell` | 执行 Shell 命令（常驻命令拦截 + 破坏性命令黑名单 + Windows 兼容检测；workdir 子目录、超时自动转后台） |
| `get_context_remaining` | 模型自查上下文已用/剩余 token 预算 |
| `current_time` | 返回当前 UTC 时间（不依赖 shell，跨平台安全） |
| `ask_user` | 模型向用户批量提问（一次多题，每题必须带 options 选项；支持多选与自由输入） |
| `plan_enter` | 任务复杂时建议切换到 Plan Mode 先规划再实施 |
| `explore` | 派发只读探索子代理：独立上下文并行调研，不修改文件不执行命令，完成后只汇报结论 |
| `plan_exit` | Plan Mode 下方案完成后请求切换到 Build Mode 开始实施 |
| `todowrite` | 创建和维护结构化任务列表（全量替换，驱动任务清单面板） |

另有可选的 MCP 外部工具，见 [MCP 扩展](/guide/mcp)。TUI 内 `/tools` 可查看全部可用工具及中文说明（MCP 工具带 `[MCP] <服务器名>` 前缀与审批标记）。

## 工具审批

`write_file` / `patch_file` / `run_shell` 为高危工具（另有配置 `risky: true` 的 MCP 服务器工具），执行前输入框位置会临时显示**黄色边框的审批选项**（第一行工具名 + 单行参数摘要，随后两个选项）：

| 按键 | 含义 |
| --- | --- |
| `↑` `↓` | 在 `1 允许` / `2 拒绝` 间移动选择 |
| `Enter` | 确认当前选项 |
| `1` / `2` | 快捷同意 / 快捷拒绝（免导航） |
| 其他按键 | 不消费审批，保持挂起 |

鼠标支持：滚轮在选项框内上下滚动与 `↑`/`↓` 等效，左键点击选项行直接选择并确认（信息行与框内空白不响应，框外操作不受影响）。

审批提示只显示工具名与单行参数摘要（`run_shell` 显示命令、`write_file` / `patch_file` 显示路径，均截断到 100 字符），没有内容预览，也没有「全部允许 / 永久记住」入口，拒绝时不附带反馈文字。`plan_enter` / `plan_exit` 确认也走同样的内联选项（`1 是` / `2 否`，前者开启 Plan Mode、后者切换到 Build Mode）。

审批范围可用 `~/.codenect/tool_approval.json` 调整：任意内置 / MCP 工具可强制审批或豁免（含 `*` 兜底键），详见[配置文件](/reference/files)。

### 无审批模式

设置环境变量 `AI_PROG_NO_APPROVAL=1`（settings.json 或系统环境变量均可，启动生效）后跳过全部审批：

- 所有内置 / MCP 工具免审批直接执行（优先级高于 `tool_approval.json` 的任何配置）
- `plan_enter` / `plan_exit` 自动切换模式，不再询问
- `ask_user` 不弹框，改为返回占位答案（Agent 凭假设继续并在回复中标注）
- TUI 启动时显示红色警告提示该模式已开启

TUI 内可用 `/noapproval on` / `/noapproval off` 即时切换并持久化。适合无人值守的批量 / 自动化场景，日常使用请保持关闭。

## Agent 提问（ask_user）

当 Agent 需要用户决策或澄清时，会调用 `ask_user` 工具。输入框位置显示**蓝色外框的问答框**（与审批黄框区分），自下而上为：底部提示行 → 编号选项列表（选项说明显示在选项下方；单选选中后行尾加 `✔`，多选题勾选为 `[✔]`）→ 题目区（只显示问题文本，白色加粗）→ 顶部步骤进度条。

**每题末尾固定有「输入回答」与「跳过」两项**：Agent 的提问一律带候选选项，任何题也都可以选「输入回答」自由输入文字作答——该行本身就是输入框（与普通选项行同观感，无边框），高亮移到该行即可直接输入，输入文字自动打勾、清空自动取消勾选；多选题中「输入回答」与其它选项可同时勾选，答案以顿号一并拼接。

顶部进度条每题一个步格：`☐` 未答 / `✔` 已答（当前题加粗高亮），末尾 Submit 步格——全部题目答完变 `✔`，表示可进入汇总提交。

| 操作 | 效果 |
| --- | --- |
| `↑` `↓` | 在当前题的选项间移动选择（移到「输入回答」行可直接输入） |
| `←` `→` | 在多题之间切换（可回头修改答案）；`→` 在最后一题进汇总确认页 |
| `Enter` | 单选题 = 选中并前进；多选题 = 切换勾选；「输入回答」行 = 提交文字答案 |
| `Space` | 多选题切换勾选（与 Enter 等效） |
| 输入文字 | 输入回答自动打勾；空文本自动取消勾选 |
| 选「跳过」 | 该题按未回答处理，Agent 将凭假设继续 |

汇总确认页（答完最后一题或末题按 `→` 进入）列出全部问答（`● 问题 → 答案`，答案绿色高亮，未答标记「未回答」）：

| 操作 | 效果 |
| --- | --- |
| `Enter` | 提交全部答案回填给 Agent |
| `←` | 回末题逐题修改，修改后答完再回到汇总页 |

未答的题也可直接提交（按「未回答」处理）。鼠标支持：答题页滚轮移动高亮、左键点击选项行直接选中（等同 Enter）；汇总页滚轮滚动列表，回题修改用 `←`。

答案回填格式 `"问题"="答案"`（未答标记「未回答」）；多选题答案以顿号拼接所选选项（如 `"选择配置"="日志增强、性能优化"`），同时勾选了「输入回答」的题，文字答案一并拼接在末尾。

## 工具结果展示

执行后 TUI 对话区中（以下为内置默认，均可通过 `~/.codenect/tool_display.json` 调整，见[配置文件](/reference/files)）：

- `write_file`：折叠显示前 10 行代码预览（`preview_lines` 可配行数，0 行只显示摘要），展开看完整语法高亮
- `patch_file`：展开显示 unified diff（红色 `-` / 绿色 `+` 着色）
- `run_shell`：折叠单行显示 `cmd: {命令}` / `sh: {命令}`（`cmd_preview_chars` 控制截断保证单行；`preview_lines` 可配为追加截断输出，默认 0 行不显示），展开为标签与命令同一行（长命令软换行与命令列对齐不顶行首）+ 完整输出
- `read_file`：展开为语法高亮（自动剥离 `行号|` 前缀，行号延续，行号列与 diff 一致）
- `list_files` / `todowrite` / `ask_user` / `webfetch` / `web_search` / `skill` / `task`：默认折叠
- `web_search` 展开只显示条目（标题 + 链接），不显示摘要正文；`webfetch` 展开只显示 URL / 标题 / 格式头部，正文不显示；`skill` 展开显示技能指令正文
- `search`：默认展开
- `search` / `glob` 折叠态与展开态头部显示 `"pattern" → N 处/个文件`（搜索参数 + 结果数量，降级标注 / 无结果 / 截断提示行不计入）；无参数的历史会话回退结果摘要
- 工具调用头与结果摘要头部：格式化名称（如 `Read (src/auth.py)`、`cmd  echo hi`，run_shell 前缀实际执行 shell 名）；文件类工具（read / write / patch / list）括号显示路径——工作区内为相对路径、工作区外为绝对路径

## run_shell 的行为与安全

- **常驻命令拦截**：`npx vite` / `npm run dev` / `uvicorn` / `python -m http.server` 等常驻服务器命令秒返错误，指引手动运行
- **破坏性命令黑名单**与 Windows 兼容检测
- **超时转后台**：不传 timeout 时，运行超过 `AI_PROG_SHELL_TIMEOUT`（默认约 2 分钟）自动转后台继续跑（输出实时写入 `logs/shell_outputs/`，保留 7 天），AI 依据 PID 与输出文件判断卡死与否，按交接消息中的终止命令终止（Windows `taskkill /T /F /PID`，POSIX `kill -9 -PID` 杀进程组）；显式传 timeout 则到点强杀进程树
- **Doom Loop 防护**：同一工具 + 相同参数连续 3 次调用会被自动拦截并提示 Agent 换方法
- **编码兼容**：子进程输出按 UTF-8 → GBK 依序解码（GBK 回退仅 Windows），中文 Windows 下 emoji / 中文混合输出不乱码不报错
- **平台适配**：Windows 上拦截 `date` / `ls` / `pwd` / `cat` / `clear` 并秒返替代命令；System Prompt 按平台注入 shell 指引与使用陷阱（明确禁止用 here-string / heredoc / echo 写文件内容）
