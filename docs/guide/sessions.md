# 会话管理

会话保存在用户目录 `~/.codenect/sessions/<工作区>/<id>.json`（按工作目录分文件夹），有用户消息时自动保存。工作区目录名由路径编码而来：纯 ASCII 路径沿用旧规则；含非 ASCII（如中文）的路径带 `-<哈希8位>` 后缀（修复了旧规则下不同中文工作区目录互相碰撞、会话串档的问题）。

> 升级后旧规则的非 ASCII 工作区会话目录不会自动迁移（碰撞过的目录数据已混在一起，无法安全拆分）：需要保留时，把 `sessions/` 下对应旧目录改名为新规则名字即可，其余不受影响。

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `/save` | 手动保存当前会话 |
| `/sessions` | 列出所有历史会话（含缩略路径和标题） |
| `/resume` | 恢复本工作目录的历史会话（内联选择：↑↓ / 滚轮移动高亮，点击 / Enter 恢复，Esc 取消） |
| `/load <id>` | 加载指定会话（自动切换工作目录） |
| `/session` | 查看当前会话详细信息 |
| `/report` | Token 用量统计（按模型 + 按会话 + 费用） |

## 会话回溯（双击 Esc）

双击 `Esc`（Agent 空闲、无审批 / 提问挂起时；输入可为空，非空输入不丢失）打开轮次选择器：

1. `↑` `↓` 选轮次 → `Enter` 回退；`Esc` 取消；列表末尾的「撤销上次回退」行 `Enter` 直接撤销
2. 该轮及其后**无任何代码改动记录**时直接执行（仅对话）
3. 有改动记录时进二级菜单选方式：
   - `1` 代码 + 对话（默认）：该轮问题回填输入框、其后对话与子代理视图截断落盘、Agent 改过的文件逐文件回滚——不碰你未提交的手动改动
   - `2` 仅对话：文件不动
   - `3` 仅代码：只回滚文件，对话不动
   - `↑` `↓` 或数字键选、`Enter` 执行、`Esc` 返回一级
4. 执行后只要还没提交新消息（后台子代理汇报注入不影响），再次双击 `Esc` 选「撤销上次回退」按上次操作对应恢复：文件整树恢复——**不删除你回退后新建的文件**，但回退时被删的新建文件也不会恢复
5. 会话压缩过的历史轮次仍可回滚文件（压缩时快照记录随用户原话保留）

### 文件快照机制

文件回滚基于影子 git 仓库（`~/.codenect/snapshots/<md5>`，与用户项目是否 git 无关，用户 .gitignore 天然生效）：每轮工具执行前后自动记录文件差异，回退时按截断范围内消息的快照记录逐文件恢复（只碰 Agent 动过的文件，同文件取最早一次）。git 不可用或 `AI_PROG_SNAPSHOT=0` 时静默禁用（只回会话）。
